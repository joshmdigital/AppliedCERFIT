# Thesis Code Repository

This repository contains the data files and R scripts used for the thesis:

**Estimating Individualized Treatment Effects and Optimal Treatment Regimes in Observational Studies: The CERFIT Package for R**

## Overview

The code in this repository supports the applied analyses conducted for the thesis. The analyses focus on estimating individualized treatment effects (ITEs) and optimal treatment regimes in observational studies using the CERFIT R package.

The repository includes the data and R scripts used to fit CERFIT models, estimate propensity scores, run analyses, and generate thesis outputs.

## Repository Contents

This repository contains:

- Data files used in the thesis analyses
- R scripts used for analysis, modeling, figures, and tables

## Requirements

The analyses are written in R. The following R packages are used:

```r
library(KMsurv)
library(survival)
library(haven)
library(dplyr)
library(purrr)
library(CERFIT)
library(tidyr)
library(ggplot2)
library(plotly)
library(knitr)
library(kableExtra)
```

Additional package dependencies may be installed automatically when these packages are installed.

## Reproducibility

To reproduce the analyses, install the required R packages and run the R scripts in the appropriate order. Some scripts may depend on data files or intermediate objects generated by earlier scripts.

Where random sampling or random forest fitting is used, random seeds are set when appropriate to improve reproducibility. Exact results may vary slightly depending on package versions, operating system, and random-number generation behavior.
